# System Architecture

## Overview
The AI-powered Project Management SaaS application is built using a decoupled architecture, with a Next.js frontend and a FastAPI backend.

## Frontend
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Components**: Radix UI primitives & Lucide React icons
- **State & Hooks**: React Hooks, Custom Features Hooks
- **Communication**: REST API (Fetch) & WebSockets (for real-time collaboration)

## Backend
- **Framework**: FastAPI (Python)
- **Database**: PostgreSQL (SQLAlchemy ORM)
- **Migrations**: Alembic
- **Task Queue**: In-memory background tasks / Celery (depending on deployment)
- **AI Integrations**: Groq API (LLM inference), SentenceTransformers (Embeddings)
- **Vector Database**: Chroma / pgvector for document chunk indexing

## RAG Pipeline
1. Documents (PDF, DOCX, TXT, CSV) are uploaded via the Documents tab.
2. The backend extracts text, chunks it into overlapping segments, generates embeddings, and stores them in the vector database.
3. When the user queries the AI Copilot, semantic search retrieves relevant chunks, which are injected into the prompt context for the LLM.
